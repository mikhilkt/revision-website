# Revision Hub

A dark-themed static revision website for lecture-note PDFs. It automatically reads PDF files from the `NLP`, `BI`, and `IS Security` folders using the GitHub Contents API.

## Adding notes

Upload `.pdf` files to the appropriate folder. They will appear on the website automatically after GitHub's API cache updates.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.
